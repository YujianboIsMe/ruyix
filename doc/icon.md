# 标签
标签页的文字前面加一个小图标
- 如果是只读文件，比如帮助文档，加个小图标🔒
- 如果是终端，🖥️


## 普通文件图标
- python文件，图标🐍
- rust文件，图标🦀
- html文件，图标🌏
- css文件，图标🎨
- js文件，图标Ⓙ
- java文件，图标☕
- md文件，图标Ⓜ️
- png/jpg/jpeg/icon文件，图标🖼️
- .gitignore文件🚫
- .toml ⚙️
- .json 🧩
- 其他未识别的普通文件，图标📄

## 文件夹图片
- 🈳 空文件夹
- ⬇️展开的文件夹
- ➡️折叠的文件夹
文件夹不必两个图标。
现在的文件夹是两个图标，一个右/下符号，一个文件夹符号。
