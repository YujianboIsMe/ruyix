# ISSUE-03
【智搜】菜单报错：
Failed to start Smart Search fl gdrant shard k Service runtime error. 
cannot create edge shard path already contains segment data。

 - 方案 A — 诊断优先：load 失败时先检查 segments 是否已有数据；有数据就不再尝试 new，把 load
  的原始错误（如"维度不兼容"）如实报给用户，并提示删掉 ~/.darkhorse/code/qdrant/ 后重建索引。
 - 方案 B — 自愈：load 失败且存在旧数据时，把数据目录改名备份（qdrant.bak-<时间戳>）后重建空库，同时清空项目 rag.toml
  里的文件 hash 记录，强制下次索引全量重编。向量可从 API 重新生成，代价只是重新调用嵌入 API。

最终方案 A + B
