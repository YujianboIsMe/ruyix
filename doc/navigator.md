# 导航区
导航区是多标签页的。
分以下几种标签
1. 项目文件
2. 终端资源
3. 运行目标

## 项目文件
使用树状结构UI，显示已打开项目的文件结构。
隐藏以.开始的文件夹。
但是不能隐藏以.开始的文件，因为这些文件很重要。比如：
- .gitignore
- .aiignore

## 终端资源
用无序列表显示以下条目：
1. Power Shell
2. Cmd
3. Ubuntu
4. Claude
5. Python
6. Node.js
7. Git Bash

运行的逻辑一样，都是在编辑区新开标签页。
每个终端都可以有两种打开方式：
1. 模拟终端
2. 新窗口

在【导航栏-终端资源】里每个条目的右边加个小图标🪟，这是窗户图标，点击这个图标以新窗口打开，使用操作系统的终端程序。
点击终端文字本身就是默认的模拟终端方式。
