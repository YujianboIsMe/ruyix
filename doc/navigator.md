# 导航区
导航区分两种运行时状态：
1. 无项目状态
2. 打开项目状态

## 无项目状态
导航区只有一个标签：项目列表
从全局配置里读取项目列表，显示出来。
点击项目可以打开项目，这样就实现了记住历史项目。

## 打开项目状态
在打开导航区是多标签页的。
分以下几种标签
1. 项目文件
2. 终端资源
3. 运行目标

### 项目文件
使用树状结构UI，显示已打开项目的文件结构。
隐藏以.开始的文件夹。
但是不能隐藏以.开始的文件，因为这些文件很重要。比如：
- .gitignore
- .aiignore

文件图标
参见[icon](./icon.md)

右键菜单
在项目文件里，禁用chromium的右键菜单，替换为我们自己的右键菜单。
右键菜单分两种情况：
1. 文件夹
2. 文件

文件夹右键菜单内容：
1. 删除/Delete
2. 重命名/Rename
3. 创建文件/New File
4. 创建文件夹/New Folder

文件右键菜单内容：
1. 删除
2. 重命名

### 终端资源
用无序列表显示以下条目：
1. Power Shell
2. Cmd
3. Ubuntu
4. Claude
5. Python
6. Node.js
7. Git Bash

运行的逻辑一样，都是在编辑区新开标签页。
每个终端都可以有两种打开方式：
1. 模拟终端
2. 新窗口

在【导航栏-终端资源】里每个条目的右边加个小图标🪟，这是窗户图标，点击这个图标以新窗口打开，使用操作系统的终端程序。
点击终端文字本身就是默认的模拟终端方式。

### 运行目标
运行目标是一个列表。
每个条目右边都有两个功能：
1. 图标🗑️，点击可以删除运行目标。删除运行目标通过命令系统执行。
2. 图标✍️，修改运行目标
