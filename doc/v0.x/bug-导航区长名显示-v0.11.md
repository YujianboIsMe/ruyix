# 方案：导航区长名（文件路径）怎么显示
## 归属版本：v0.11 · 状态：**已实施**（2026-09-24）· 方案由用户拍板

> 用户拍板原话：*"不做横滚，长名走省略号 + 悬停显示全名（title）。树最稳、零抖动、位置永远整齐；
> 读全名靠悬停。"*

## 1. 结论

**导航区不做横向滚动**：长名交给 `.tree-name` 的 `text-overflow: ellipsis` 收成省略号，
**完整路径由行上的 `title` 悬停给出**（`ui/main.js::renderTreeEntry` 里 `node.title = entry.path`；
目录的刷新按钮自带 `title=刷新`，两层不冲突）。

## 2. 走过的路：两版横滚都被否（别再走第三遍）

| # | 做法 | 用户实测结果 |
|---|---|---|
| 1 | 列表 `min-width: max-content` + `.nav-content { overflow: auto }` —— 内容按需撑宽、出横向滚动条 | "有点瑕疵"：长路径触发横滚时，**刷新符号盖在文件路径上**（钉住的按钮 + 滚动的文字） |
| 2 | 行 `width: fit-content` + 行内按钮 `position: sticky; right: 0` —— 把按钮钉在可视区右缘 | "**不行，回滚** —— 太丑了，而且导航树会抖动" |
| 3 | **采纳** | 零抖动、行内按钮位置永远整齐；全名靠悬停 |

### 三条几何上的死规矩（踩出来的，写在这里省下一次返工）

1. **钉住的元素 + 滚动的文字 = 遮挡**。把按钮 `sticky` 在可视区右缘，长名从它底下滚过去 ——
   必然压字，换谁写都一样。要么按钮在**行内**（谁也别钉），要么别滚。
2. **`min-width: 100%` 是陷阱**：那个 `100%` 相对**最宽的父级**解析，等于把每行都撑到"最宽那一行" ——
   实测普通目录行的刷新按钮被推到 **557px**，直接滚出 260px 的侧边栏。
3. **内容一撑宽，"出现/消失"就会改布局**：悬停伪元素、横向滚动条一冒出来，行宽/表宽就变 ——
   看起来就是"树在抖"。想要零抖动，内容宽度必须是**确定的**（这里 = 面板可视宽度）。

## 3. 落点

- `ui/styles.css`
  - `.nav-content { overflow-x: hidden; overflow-y: auto }` —— **显式**关横向。只写 `overflow-y: auto`
    会让 x 侧按规范算成 `auto`，内容一过宽就又冒出横条；
  - 行保持"面板可视宽度"，`.tree-name` 原有的 `text-overflow: ellipsis` 生效；
  - 注释里写明**不要**再加 `min-width: max-content`、**不要**给行内按钮加 sticky。
- `ui/main.js::renderTreeEntry`
  - `node.title = entry.path || entry.name` —— 被省略号吃掉的部分靠它补。

## 4. 判据（`scripts/nav-layout.js`，ui-smoke **U44**，10 条全通）

```
短内容：内容区 259px（滚动宽 259）｜横条 0px｜纵条 0px
长内容：内容区 249px（滚动宽 249）｜横条 0px｜纵条 10px
长文件名：格子 157px（内容 477px）｜text-overflow=ellipsis｜行 title=有
  ok  短内容时没有横向滚动条（视口 259px 装下 259px）
  ok  长内容时也没有横向滚动条（横条 0px）—— 导航区不做横滚
  ok  内容没有超出视口（249px ≤ 249px）：长名是被省略号收掉的，不是靠滚动读的
  ok  长名走省略号（477px 的内容收进 157px 的格子）
  ok  每一行都带 title（悬停能读到完整路径）
  ok  长名行的 title 就是完整路径（…\ApplicationPropertiesOfTheCloudShopAuthorityServiceIntegrationEnvironment.java）
  ok  所有目录行的刷新按钮右边缘对齐（4 行，散布 0px）—— 位置永远整齐
  ok  按钮都在可视区内（最右 237 ≤ 导航右界 260）
  ok  长目录行：刷新按钮在名字右侧（名字右 212 ≤ 按钮左 212），不遮字
  ok  纵向仍可滚（内容 936px > 视口 562px）
```

`ui-smoke` **307/307**、check-style PASS、clippy 0、fmt 干净、引擎 351 / 宿主 121 不变。

## 5. 边界（没验的）

- **悬停本身量不到**（无头浏览器没有鼠标交互）：判据只到"`title` 属性在位、且等于完整路径" + 几何。
- 真机观感（省略号截断位置、tooltip 的出现位置与机器有关）需重启 ruyix 肉眼过一眼。
- **能力面板**（MCP / A2A / 工具 / 技能）的列表**没动**：那里的行长这样也装得下；以后若出现过宽，
  按同一套规矩办 —— **先想清楚"谁定宽度"，别急着上横滚**。
