## 智搜
点击后弹出确认弹窗，说明资源消耗与隐私影响（代码会发送到嵌入 API 编码）。
弹窗内含两个输入框：
- 嵌入模型 API 地址（示例预填 DeepSeek 嵌入 API 地址 https://api.deepseek.com/v1/embeddings）
- 向量维度（默认 1024）

按钮行为：
- 接受：保存配置（全局 rag.toml）→ 启动 qdrant-edge → 全量索引
- 暂不接受：关闭弹窗，下次点击再弹
- 永久禁用：写全局配置 permanently_disabled = true，隐藏【智搜】菜单

## 记忆
**没有下拉、没有子菜单** —— 点击后直接在中央编辑区打开「记忆」面板标签页（与「服务」面板同一套标签页惯例：
已有面板就复用并切过去，不重复开；面板只在**第一次点菜单时**才被建出来）。

面板由 `ui/scripts/memory.js`（`window.MemoryUI`）实现，菜单项是 `ui/index.html` 里的 `#menu-memory`，
接线在 `MemoryUI.attach()` —— 由 `ui/scripts/main.js` 的 `initApp` 在**启动期**调用一次。

为什么不把绑定写在面板的 `build()` 里：面板是点菜单才建的，而 `build()` 只在面板已建之后才跑，
绑在那儿就成了先有鸡还是先有蛋，菜单等不到第一次点击、那条绑定一辈子没执行过，按钮看上去就是死的。
（历史 bug：「记忆」按钮点不动，就是这个原因。）

### 面板内容
- **当前信念**：现在认为什么为真（被推翻的条目不在这一列，它们没被删，只是离开了当前事实）
- **修订链（why）**：点一条看完整修订链 —— 谁、在什么时候、以什么依据、用什么算子改的它
- **as-of**：按时间点查回旧值（历史一条不丢的可操作形态）
- **收据（receipts）**：有界注入块逐出的条目留下「丢了什么 / 怎么换回来」

面板不自己算：`mem_now` / `mem_why` / `mem_as_of` / `mem_receipts` 全部由引擎（`crates/harness-engine/src/mem/`）回答。
写入是显式的：`记一条` 走人写入口（origin=human）。向量腿缺席（缺嵌入模型）时退化为纯词法检索，不是错误但会直接显示 `embed_reason`，不吞掉。
