# 项目
在0.0.2版本开始对项目进行重构

## 属性
项目属性，目前三属性：未来扩展
1. 项目名称 name
2. 项目路径 path
3. 项目语言 lang

项目语言默认为Unknown。
不同语言图标如下：
1. Ⓤ Unknown 未知语言
2. Ⓜ Mix 混合语言
3. Ⓙ Java语言
4. Ⓒ C/C++/C#语言
5. Ⓟ Python语言
6. Ⓡ Rust语言
7. Ⓦ Html/javascript/css语言
8. Ⓖ Golang语言
9. Ⓓ Document或笔记类：pdf/word/markdown
10. Ⓚ Kotlin语言

语言的设置通过 ✍️ 修改项目弹窗完成：弹窗里可修改图标（语言）与名称，路径只读不可修改。

对于旧版只有项目路径的配置，在【菜单-项目】下有个子菜单【迁移配置】

## 项目列表
项目列表是有项目的条目组成的。
每个项目条目,显示三个信息：
1. 项目图标
2. 项目名称
3. 项目路径，太长就用省略号(ellips)隐藏

在项目条目上，还有两个按钮：
1. ✍️修改项目，可以修改图标、名称，但是不能修改路径
2. 🗑️删除项目（从项目列表移除，不删除项目文件夹）

## 项目切换

核心思路：把"关闭 + 打开"合并为一个 switch 语义，并让项目列表始终可达。

### 命令升级
open project <path> 升级为"打开即切换"（命令层）

  在 openProject()（command.js:1247）开头加判断：

  - 路径 == 当前项目 → 状态栏提示"已是当前项目"，直接返回
  - 路径 != 当前项目 → 先执行 teardownProject()（复用 closeProject 的清场逻辑：清 tabs、逐个关 PTY、清文件树），再走原有
  open 流程

  这样命令栏、菜单、列表点击三条路全部天然获得切换能力，零新增命令动词。

### 标题栏切换
	
标题栏项目名 → 快速切换下拉（零鼠标移动路径）

点标题栏的项目名，弹出 get_projects 列表的下拉，点击即切换。
数据（已有逻辑 main.js:1640），当前项目那一行高亮 + ✔ 标记
适合把鼠标已经放在顶部的场景。
 
## 多实例
目前启动第二个darkhorse-code 实例后，会开启上次打开的项目，不太友好。
正确做法是新实例不打开项目，处于一个无项目状态。因为打开重复的项目毫无意义。
